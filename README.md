## 🛠️ Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/growthstack.dev.git
   cd growthstack.dev
   ```

2. **Setup Environment Variables:**
   Copy `.env.example` to `.env` and securely add your API keys.
   ```bash
   cp .env.example .env
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application locally:**
   ```bash
   uvicorn chatbot_api:app --reload
   ```

🔒 **Security Note**
Never commit `.env` files. Always use environment variables in your deployment hosting dashboard.
